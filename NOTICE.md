# Attribution and source boundaries

IproK ontology: Venkatesh Kone; contributor Prof. Gangadhar Mahesh. Retained from https://github.com/konevenkatesh/IprokDoc at commit `ee4cf206af08a47db3363fa4404ac51cce1868de`, retrieved 19 October 2026. Original source metadata declares version 0.1.0 and CC BY 4.0. The exact historical IRIs, including their capitalisation and module namespaces, are preserved.

Niyoj runtime schema: Venkatesh Kone, BIMSaarthi Technologies. Retained from the platform repository at commit `59bb8c2ae61228cd21778cc6beae523331f4529a`. The core source declares CC BY 4.0. Provenance and hashes are in `schema/niyoj/source.json`. The site-intelligence file shares the canonical BIMSaarthi namespace. It is combined with the core only for its separate explorer index.

The original IproK documentation, source representations and supporting resources are retained for attribution in `legacy.html`, `legacy/`, `resources/`, `webvowl/` and `OOPSevaluation/`. Those supporting evaluations are archival material, not new validation results.

Changes made on 19 October 2026: new interactive website, source-derived indexes, explanatory reading guides, constructed query diagnostics and aligned N-Triples export. The original N-Triples file differs from the Turtle/RDF/XML/JSON-LD graph in its representation of disjointness lists. This website uses the unchanged Turtle source as its export baseline, corroborated by the existing RDF/XML and JSON-LD files. The original N-Triples remains in `legacy/ontology.nt`; this correction is not represented as an original historical release.

Explanations marked as editorial are derived reading aids and do not add axioms to either source ontology. Illustrative record names are constructed examples. This website contains no actual project records, Niyoj photographs or screenshots, credentials, model weights or historical experimental findings.

No equivalence mapping between historical IproK and the BIMSaarthi namespace is asserted. Niyoj's source header still says “M1 subset / 0.1.0”, despite broader implemented coverage. This site identifies the source by commit rather than inventing a new ontology release.
